# 管理员端静态原型说明

本目录中的管理员页面是第二阶段开发的视觉、字段和交互参考，不连接真实接口，也不写入数据库。

## 页面入口

建议先打开：

```text
管理员登录.html
```

登录按钮会进入运营看板，左侧菜单可以切换其他页面。

## 页面清单

| 页面 | 用途 |
| --- | --- |
| `管理员登录.html` | 管理员登录和演示账号提示 |
| `运营总览.html` | 用户、学习、掌握度和 VIP 运营数据 |
| `用户管理.html` | 用户筛选、状态和学习摘要 |
| `题库管理.html` | 题目、知识点和审核状态 |
| `学习详情.html` | 用户错题、复习和学习轨迹 |
| `订单管理.html` | VIP 订单和支付状态 |
| `系统日志.html` | 操作日志、支付异常和 AI 降级记录 |

## 开发使用规则

- 页面布局、字段名称、状态标签和交互状态以此原型为参考。
- 页面中的数据是 Mock 数据，仅用于确定展示效果。
- 正式开发时在现有 Vue 项目中实现，不要继续维护第二套独立 HTML 业务页面。
- 接入真实接口后保留加载中、空数据、失败和无权限状态。
- 如果真实业务需要新增字段或改变状态，先更新开发契约，再同步修改页面。

公共样式和原型交互分别位于：

```text
admin-prototype.css
admin-prototype.js
```
